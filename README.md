# Blind Hunt VR website

The website lives in `public/`. It uses static HTML, CSS, JavaScript, and self-hosted assets.

## Run locally

From the repository root, run `python3 -m http.server --directory public 8080`, then open [localhost:8080](http://localhost:8080).

## Cloudflare Pages

[Import this GitHub repository into a Pages project](https://developers.cloudflare.com/pages/get-started/git-integration/) with these settings.

| Setting | Value |
| --- | --- |
| Production branch | `main` |
| Framework preset | None |
| Root directory | Repository root |
| Build command | Leave blank |
| Build output directory | `public` |

The Download for Quest buttons open the game's [itch.io page](https://sxenolith-del.itch.io/blind-hunt-vr2). The Backrooms image is concept artwork.
